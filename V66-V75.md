# V66–V75 — programmable render layer + advanced backend routing

## V66–68 — compositor contract
- Pure `CompositorPlan` compiled from timeline state.
- Stable layer ordering.
- GLSL blend catalog (Normal/Add/Multiply/Screen/Overlay/Darken/Lighten).
- `ProgrammableCompositor` contract isolates the future two-input framebuffer renderer.

## V69–72 — advanced native backend
- Deterministic multi-input FFmpeg `filter_complex` builder.
- `content://` sources are materialized to private cache files before native execution.
- Absolute timeline offsets are preserved for video overlays and audio mixing.
- Full-frame advanced blend modes use FFmpeg `blend`.
- Audio from V1 and A1 is delayed and mixed.

## V73–75 — truthful routing
- Hilt provides a routed exporter.
- Media3 remains the default path for supported edits.
- FFmpeg is selected only for the advanced subset it actually implements.
- Two-input transitions and positioned blends are explicitly blocked until the programmable compositor is wired.
- CompositionPlayer uses replayable cache for more accurate effect updates and scrubbing, with MultipleInputVideoGraph.

## Architectural boundary
Media3 `GlEffect` is a one-input shader-program API. The current public `MultipleInputVideoGraph` supports multiple input streams and composition-level `VideoCompositorSettings`, but arbitrary source/destination blend equations belong in a dedicated compositor/video-graph implementation. This release therefore keeps that contract separate rather than claiming a one-input effect is a two-input compositor.
