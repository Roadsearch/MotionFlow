# OpenEditVideo V46–V50 — real multi-layer composition

This revision turns the editable timeline into an absolute-time Media3 Composition.

## V46 — absolute timeline exporter
- one video/image sequence per visual layer
- `EditedMediaItemSequence.Builder.addGap()` preserves timeline offsets and gaps
- output is no longer silently shortened by closing gaps

## V47 — multi-track video compositing
- background sequence
- V1/V2/V3+ visual sequences
- z-order follows track ordering
- `VideoCompositorSettings` evaluates transform/opacity at presentation time
- animated X/Y/scale/rotation/opacity reach the composition compositor

## V48 — masks + text overlays
- custom SDR `MaskEffect` (rectangle/circle/linear/radial)
- feathering
- text overlays rendered as transparent image sequences using Media3 `TextOverlay` + `OverlayEffect`

## V49 — timeline audio positioning
- video-track audio on V1 remains in its sequence
- A1 clips use independent audio-only sequences
- `addGap()` preserves their absolute timelineStartMs
- per-clip gain uses Media3 `GainProcessor`

## V50 — explicit capability contract
- advanced blend modes remain blocked until a programmable source/destination compositor is available
- non-cut transitions remain blocked because Media3 Composition does not generally provide them
- unsupported features are rejected instead of silently dropped

## Verification
- source integrity checks pass
- Gradle compilation cannot be executed in the sandbox because the Android SDK/Gradle launcher are not installed
