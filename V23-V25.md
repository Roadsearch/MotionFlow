# OpenEditVideo V23-V25

## V23 - GPU rendering foundation
- Shared GPU effect factory using Media3 `GlEffect` implementations.
- Brightness, contrast, HSL, blur, alpha, rotation.
- Same effect model can be attached to preview and Transformer export.

## V24 - Multi-input composition preview
- `CompositionPreviewController`.
- `CompositionPlayer` configured with `MultipleInputVideoGraph.Factory`.
- Composition remains the single source of truth for preview/export.

## V25 - Chroma key
- Custom `GlEffect`/`BaseGlShaderProgram`.
- GLSL RGB-distance keying with threshold and softness.
- SDR path for now; HDR requires a dedicated linear/BT.2020 shader path.

## Important
`CompositionPlayer` is still an experimental API and Media3 documents multi-asset preview as active development. Transformer `Composition` supports multiple sequences and overlapping layouts, but video/audio crossfades are still a documented limitation.
