# V51-V55 — Advanced rendering backend

## V51 — Render planning
`AdvancedRenderPlanner` decides whether a project can stay on Media3 or needs the optional FFmpeg backend. Unsupported features are never silently downgraded.

## V52 — Transition timing
`TransitionPlanner` centralizes transition windows and alpha math for preview/export backends.

## V53 — Blend filter graph
`AdvancedFfmpegFilterGraph` contains deterministic mappings for Normal/Add/Multiply/Screen/Overlay/Darken/Lighten and a two-input blend primitive.

## V54 — Capability routing
Projects with advanced blend modes or non-CUT transitions are routed to the optional FFmpeg backend when available; otherwise export is blocked with a diagnostic.

## V55 — Tests
Added JVM tests for backend selection, blend routing, transition timing, and cross-fade alpha interpolation.

### Important
The FFmpeg graph is a pure planning layer. It does not make the default app GPL or add FFmpeg to the normal build. The existing optional FFmpeg flag remains required.
