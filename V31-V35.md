# OpenEditVideo V31-V35 — production foundation

## V31 — Build toolchain
- Android Gradle Plugin 9.4.0.
- AGP 9 built-in Kotlin (no `org.jetbrains.kotlin.android`).
- Kotlin Gradle Plugin 2.4.20.
- KSP 2.3.12 for Room.
- Compose BOM 2026.09.00.
- Media3 1.11.1.
- Java 17 / Android API 29+.

## V32 — Export
- Export runs in a `CoroutineWorker`.
- Transformer is created and accessed from one application thread.
- Progress is exposed through WorkManager `Data`.
- Cancellation propagates to `Transformer.cancel()`.
- MP4 output is published with `MediaStore` and `IS_PENDING`.
- User-visible foreground notification includes an Annuler action.

## V33 — Persistence
- Room stores the editor document as versioned JSON.
- Autosave is debounced to reduce database writes.
- Legacy all-property keyframes remain readable.
- Invalid future project versions are rejected instead of silently corrupting the state.

## V34 — Android resilience
- Persistable URI permissions are requested when media is imported.
- Export validates media accessibility and trim bounds before starting Transformer.
- Temporary export files are deleted in `finally`.
- Gallery insertion is rolled back on failure.

## V35 — tests and maintainability
- Timeline snapping and movement have JVM tests.
- Keyframe interpolation and easing have JVM tests.
- Pure timeline/model pieces avoid Android-only dependencies where practical.

## Current export boundary
The stable export path uses V1 as the canonical sequential video program and can add a sequential background-audio sequence. Arbitrary editor timeline gaps, independent V2/V3 picture-in-picture tracks and true overlapping transitions still require a dedicated multi-input compositor/export path; they are therefore not silently presented as fully rendered in this version.

## Build
Use Android Studio with Gradle 9.6 / JDK 17 and an installed Android SDK. The current environment does not contain the Gradle distribution or Android SDK, so an APK cannot be claimed as built here.
