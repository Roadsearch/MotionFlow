# V36–V40 — production hardening + OSS integration

- Hilt 2.60.1 for dependency injection.
- Room 2.8.5 for project state.
- WorkManager 2.12.0 for long-running export.
- DataStore Preferences 1.2.1 for settings.
- Kotlinx Serialization runtime 1.11.0; the project keeps the legacy JSON codec for existing documents and adds serializable domain models for the next schema.
- Coil 3.6.3 + coil-video for cached asynchronous video-frame thumbnails.
- Lottie 6.7.1 dependency ready for animated title/sticker templates.
- Per-clip EffectSettings so color/effect edits no longer mutate every clip.
- Gesture edits grouped into a single undo step.
- Export preflight before WorkManager queueing.
- Pure TimelineEditor seam with JVM unit tests.
- Open-source review documented in OPEN_SOURCE_STACK.md.

Build: open in Android Studio with JDK 17+, Android SDK 36+, and let Gradle sync resolve plugins/dependencies. This workspace does not contain a Gradle installation or Android SDK, so an assembleDebug run was not possible here.
