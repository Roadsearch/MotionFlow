# V56–V65 — GPU render foundation

## V56–58
- deterministic RenderCapabilities/RenderPlannerV2
- time-aware mask GL program
- mask uniforms refreshed per frame
- explicit HDR guard: custom SDR shader is never silently used for HDR

## V59–61
- centralized backend routing for advanced blend/transition requests
- no silent downgrade to Normal/Cut
- optional FFmpeg remains an explicit fallback

## V62–65
- render capability tests
- JVM tests for backend selection
- architecture prepared for a true two-input GPU compositor

### Important
Media3 `VideoCompositorSettings` is currently beta/development and supports time-dependent alpha/position/scale/rotation, but it does not expose arbitrary source/destination blend equations. Crossfading video/audio sequences is also currently unsupported by `Composition`. Therefore V56–65 do not falsely claim native Media3 Multiply/Screen/crossfade export; those remain routed to the optional backend or blocked.
