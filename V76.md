# V76 — Marqueurs, pistes verrouillables, CI

## Fonctionnel
- **Marqueurs de timeline** (`Marker`) : ajout au curseur, tap pour naviguer, appui long pour supprimer, persistés dans le projet.
- **Accrochage intelligent** : le curseur s'aimante aux marqueurs (seuil `SNAP_THRESHOLD_MS`) ; toggle « Aimant » dans l'en-tête de la timeline.
- **États de piste vidéo** (`TrackState`) : verrouillage (bloque déplacement/trim), muet (piste exportée sans audio), masquage (piste exclue de la composition). Undo/redo inclus.
- **Navigation par marqueurs** : `seekToNextMarker()` / `seekToPreviousMarker()` dans le ViewModel.

## UX/UI
- En-tête de timeline enrichi : toggle d'aimant, bouton d'ajout de marqueur.
- Nouvelle rangée de marqueurs sous la règle de temps.
- En-têtes de piste avec icônes cadenas / volume / œil.
- Piste verrouillée : affichage atténué, gestes désactivés (sélection conservée).
- Forme d'onde audio redessinée : enveloppe symétrique déterministe par clip.

## Qualité / release engineering
- Tests unitaires `MarkerSnapTest`.
- Workflow CI GitHub Actions prêt dans `ci/android-ci.yml` : tests unitaires + assemblage de l'APK debug à chaque push/PR.
- `.gitignore`, `gradle-wrapper.properties`, `LICENSE` (Apache-2.0) ajoutés.
- `OPEN_SOURCE_COMPONENTS.md` : cartographie des projets open source pour les blocs restants.
- Correctif : `AudioClip.sourceDurationMs` ajouté (le codec l'utilisait déjà — erreur de compilation latente).
- Les images placeholder noir/transparent sont générées à l'exécution dans le cache privé (plus d'assets binaires dans le dépôt).
